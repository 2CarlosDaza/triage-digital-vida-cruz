# ADRs

Un ADR documenta una decisión **difícil de revertir**, que afecta a varios módulos o que el enunciado pide expresamente documentar. No se crean ADRs por versiones, nombres, formato de código ni detalles menores: eso va en las guías, en el catálogo de versiones o en el README.

Formato: `NNNN-titulo.md` con estado, fecha, contexto, decisión, alternativas y consecuencias.
